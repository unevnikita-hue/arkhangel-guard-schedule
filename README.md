# Архангел — демонстрация управления графиками охраны

Рабочая версия: https://unevnikita-hue.github.io/arkhangel-guard-schedule/

Интерактивный публичный MVP на вымышленных данных. Пароль демонстрационного экрана: `KIRASA`.

Возможности: календарь полного месяца, двенадцать охранников, Drag&Drop,
назначения 6/8/12/24 часа и отпуск, поиск и карточка сотрудника,
официальное/неофициальное оформление, контроль нагрузки, удаление и возврат
сотрудника в график, настраиваемая стоимость смены, премия с основанием, общий
ФОТ, бюджет объекта, утверждение и XLSX-выгрузка.

Канонический реестр состояния проекта:
`/home/nikita/vault/docs/ops/arkhangel-guard-schedule-project-registry.md`.

> Клиентский пароль не защищает реальные данные. Репозиторий и GitHub Pages предназначены только для демонстрации.

Запуск: `python3 -m http.server 8080`, затем открыть `http://localhost:8080`.
